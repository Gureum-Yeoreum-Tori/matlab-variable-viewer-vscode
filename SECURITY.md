# Security Policy

## Supported versions

Only the latest tagged release of this unofficial fork receives security
updates. Upstream MathWorks releases follow their own support policy.

## Reporting a vulnerability

Do not open a public issue containing exploit details, tokens, private MATLAB
data, or user paths. Use GitHub's **Report a vulnerability** feature in the
Security tab of this repository. If private vulnerability reporting is not
enabled yet, open a minimal issue asking the maintainer to establish a private
contact channel without including sensitive details.

Include the fork version, VS Code version, MATLAB release, operating system,
impact, reproduction steps, and whether the issue also affects the official
MathWorks extension. Reports will be acknowledged when the maintainer receives
them; no response-time SLA is currently offered.

For vulnerabilities in the unmodified upstream extension, follow the
[MathWorks vulnerability disclosure policy](https://www.mathworks.com/company/aboutus/policies_statements/vulnerability-disclosure-policy.html).

The implementation review and current release gate are documented in
[SECURITY_REVIEW.md](SECURITY_REVIEW.md).
